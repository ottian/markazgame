# شخصيات واقعية متحركة (اختياري)

اللعبة بتشتغل من غيرها بشخصيات بسيطة. لو عايز ناس واقعية بحركة مشي حقيقية:

## من Mixamo (مجاني بحساب Adobe)
1. ادخل https://www.mixamo.com وسجّل بحساب Adobe مجاني.
2. من **Characters** اختار شخصية (مثلاً راجل، ست، راجل كبير، شاب...) ودوس **Download**:
   - Format: **FBX Binary (.fbx)**، Pose: **T-pose**، وحمّل ٣–٦ شخصيات مختلفة.
3. من **Animations** دوّر على **Walking**، علّم على **In Place**، ودوس Download:
   - Format: FBX، **Skin: Without Skin**. سمّيه `walking.fbx`.
4. وكمان **Idle** بنفس الطريقة وسمّيه `idle.fbx`.
5. حط كل الملفات في الفولدر ده (`assets/people/`).
6. افتح `js/config.js` واكتب أساميهم:

```js
characters: {
  models: ['man1.fbx', 'woman1.fbx', 'man2.fbx'],
  walk: 'walking.fbx',
  idle: 'idle.fbx',
  scale: 0.01,
  doctor: 'doctor.fbx',   // اختياري: شخصية بلبس دكتور
  nurse: 'nurse.fbx',     // اختياري
  patient: '',            // اختياري
},
```

ملحوظات:
- كل شخصية FBX حجمها ممكن يبقى ٢–١٠ ميجا، فخلّيهم قليلين عشان اللعبة تفتح بسرعة على الموبايل.
- اللعبة بتعرض الشخصيات الواقعية للناس القريبة من الكاميرا بس (٨–٢٨ حسب الجودة)، والباقي بالشكل البسيط.
- شروط Mixamo بتسمح باستخدام الشخصيات في مشاريعك، بس راجعها بنفسك.
- ينفع كمان أي ملف `.glb` متحرك بدل FBX.
