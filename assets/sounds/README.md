# أصوات حقيقية (اختياري)

اللعبة بتولّد أصواتها بالكود. لو حطّيت هنا ملفات صوت حقيقية بالأسامي دي، اللعبة هتشغّلها بدل الأصوات المولّدة
(ينفع `mp3` أو `ogg` أو `wav`):

| الملف | الصوت | نوعه |
|---|---|---|
| `engine.mp3` | موتور عربية/فان شغّال (ثابت، من غير تسارع) | لوب — اللعبة بتغيّر سرعته مع العربية |
| `siren.mp3` | سارينة إسعاف | لوب |
| `sea.mp3` | موج البحر | لوب |
| `city.mp3` | دوشة شارع/مرور في مدينة | لوب |
| `crowd.mp3` | كلام ناس في الشارع | لوب |
| `screech.mp3` | صريخ كاوتش | لوب |
| `horn.mp3` | كلاكس عربية (ضربة واحدة) | مرة واحدة |
| `crash.mp3` | خبطة عربية | مرة واحدة |
| `radio.mp3` | صوت لاسلكي/بيب البلاغ | مرة واحدة |
| `door.mp3` | قفل باب عربية | مرة واحدة |

## منين تجيبهم ببلاش
- https://pixabay.com/sound-effects/ — مجاني للاستخدام من غير ذكر المصدر.
- https://freesound.org — فلتر على رخصة **CC0** (Creative Commons 0) عشان متحتاجش تذكر المصدر.
- https://kenney.nl/assets?q=audio — حِزم CC0.

نصايح: اللوبات تكون ١٠–٣٠ ثانية ومتقطّعة بنعومة (من غير سكتة في الأول/الآخر)، وحجم كل ملف أقل من ١ ميجا.
