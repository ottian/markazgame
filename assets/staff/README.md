# صور الفريق

حط صور الموظفين هنا (يُفضّل مربعة، مثلاً 256×256، بصيغة jpg أو png أو webp)،
وبعدين اكتب اسم الملف في `js/config.js` في خانة `photo`:

```js
{ id: 'driver1', name: 'عم سعيد', role: 'driver', title: 'سواق عربية الإحضار', photo: 'driver1.jpg' },
```

الأدوار المتاحة: `driver` (سواق)، `doctor` (دكتور)، `nurse` (تمريض)، `social` (أخصائي).
ملحوظة: خُد موافقة الموظف قبل ما تحط صورته في اللعبة.
